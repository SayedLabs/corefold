date: 2026-10-24

Safer with your files
- Updating or removing Corefold no longer stops it in the middle of a conversion or a sort. It finishes first, then closes. Another program that happens to be called Corefold.exe is left alone.
- Removing Corefold deletes only its own files. Anything else you saved in its folder stays. It also won't install into a folder that already holds other things.
- If a sort is cut short (a crash or a power cut), Undo still knows what moved. Undo never moves a different file that now has the same name.
- A Cloud download is kept only if it arrived whole and matches the file in the account.
- Archive passwords are never visible to other programs.
- Repairing a damaged ZIP and unpacking stop before the disk fills up.
- A file too big for the Recycle Bin is no longer deleted for good without asking.
- Text you delete from the Clipboard history is wiped from its file too.

Capture
- Select text picks exactly the words you want: drag over them, draw a box around them, or Ctrl + click to add or remove one word.
- Text is read more accurately, light text on a dark background too. If Windows can't read Arabic yet, a "Read Arabic too…" button adds it.
- New: Win + Shift + T copies the text on the screen. Drag over any text and it's on the clipboard.
- A new editor tool bar with icons, and three line sizes.
- Arrows, boxes and text can be picked again later to move, resize, recolour or delete. Undo and Redo cover all of it.
- While you pick an area: a magnifier with the exact position and colour. The arrow keys move by 1 pixel (10 with Shift).

Cloud
- The "Add a cloud" button is always there. Sign in, add any folder on this PC, or get a cloud's app.
- Each account shows how much space is free and how much there is in total.
- A path at the top you can click, sorting by name, size or date, Preview with Space, and a list of transfers.

PDF
- A clearer page with Edit content first.
- Edit content has Find and Replace (Ctrl + F), a list of the pages with small pictures, and pages you can turn, delete and move. Undo covers all of it.

Scan (still fully offline)
- Looks in many more places: more startup places, scheduled tasks, services in odd places that aren't signed properly, add-ons forced into browsers, changed home pages and search, proxies, and policies that switch Microsoft Defender off.

Every other tool
- Startup: Microsoft Store apps and sign-in tasks are listed too, and "Start it a minute after sign-in" lets the PC be ready sooner.
- Uninstaller: Updates… shows the apps that have a newer version and updates the ticked ones.
- Clipboard: Ctrl + Alt + Win + V pastes as plain text in any app.
- Awake: stays awake while the programs you choose are open, and lets the PC sleep when the battery runs low.
- Colors: OKLCH and VEC4, add a colour by typing it, and text contrast checks.
- Unlock: Move to… and Rename… once the file is free.
- Quick menu: type part of a window's title to switch to it.
- File Organizer: keep a folder tidy by itself, once a day.
- Viewer and Player: the mouse's side buttons go to the next or previous file, drag a picture out, and Copy the path.

Also
- Safer: text and pictures from emails, file names and SVGs can't make Windows send your sign-in to another computer.
- No more small windows flashing open while Corefold starts or opens tools.
- Corefold tells you when a new version is out.
