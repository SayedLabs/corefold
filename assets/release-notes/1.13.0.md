New
- Files is now one tool, Corefold Files. One heading stays over all of it, with a bar of what you can use it for: Convert, PDF, Archive, Tidy up, Unlock and Cloud. Picking one changes only the page under the heading.
- Start page: drop any file to see everything you can do with it, or pick a use, each with a few words about what it's for.
- Settings on the heading opens the settings of the use that's open; on the start page it lets you switch off the uses you don't need (they aren't loaded at all).

Smoother
- The PDF editor gets the whole window while it's open.
