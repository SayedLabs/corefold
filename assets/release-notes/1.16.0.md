date: 2026-11-01

New
- Space and the Uninstaller are back, in the Computer section. Space shows what's filling each drive and frees up space safely; the Uninstaller removes programs and what they leave behind, with a backup you can put back. If you used them before, they come back the way you had them; otherwise they wait in Computer, switched off, until you switch them on. Startup and Virus scan rest a little longer.
- Space shows what takes the room by file type (biggest first, with how many files); double-click one to see its biggest files. The map can be saved as a spreadsheet (CSV).
- Space's clean-up can remove Windows' update copies kept for other PCs (Delivery Optimization). It's unticked, and Windows removes them its own way.
- The Uninstaller finds folders left in Program Files by apps that are gone: nothing installed points to them and they haven't changed for 60 days. They're offered unticked and go into the backup first.
- PDF editor: a click on the PDF's own text opens the whole paragraph, and the lines flow together while you type. Alignment and line spacing are kept and can be changed.
- PDF editor: a font list inside the window (search, the PDF's own font, used lately, Arabic, all fonts), underline, links, blank pages, see-through and fill, duplicate (Ctrl + D), copy and paste of marks, and "Cover all" in Find. Options sit in a side panel grouped by what they change.
- PDF: Duplicate pages (Ctrl + D) on the board of pages, and its tools sit in one bar with their names under them, like the editor's.
- Corefold installs for the whole PC, in Program Files, where only administrators can change its files. Windows asks for permission at install and at each update; if you say No, Corefold keeps running and the update waits on the Updates page. An older copy in your own folder is moved over with your desktop icon, taskbar pin and Start with Windows kept.

Safer
- Space's clean-up looks again right before it removes anything: a temporary file used again since it was found stays, and a browser's or app's cache stays if the browser or app was opened meanwhile.
- Your own Windows folders (Desktop, Documents, Downloads, Pictures, OneDrive and the like) can't be sent to the Recycle Bin from Space's map. What's inside them still can.
- Space's "The previous Windows" removes the links inside the old Windows folder before taking it over, so it can never change the owner of today's files through them.
- Windows' own programs are found from Windows itself, so a changed setting can't point Corefold somewhere else.
- The administrator helper checks that its plan wasn't changed after the permission prompt, and stops if it was. Undoing a clean-up takes back only what Corefold itself set to be removed at restart.
- The Uninstaller removes emptied folders only from the folders it walked, never through a link into another place. Unlock refuses a move at restart whose destination is reached through a link.
- More kinds of email attachments ask before they open.

Fixes
- Cloud no longer sets your accounts aside when another program holds their file for a moment: it reads it again a few times first.
- Splitting a file into two parts with the same name gives " (2)", " (3)" and so on, instead of one replacing the other.
- PDF pictures, text and previews no longer clash when more than one is made at the same time.
- Cloud's buttons turn into icons before they push the used-space text out of a narrow window.

Clearer
- A calmer look: one compact heading for every tool, one accent button, a Suggested row after a file is dropped, and an empty History that says so.

Smoother
- The Home page no longer keeps the processor busy while the window just sits open.
