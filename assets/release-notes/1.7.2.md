# Corefold 1.7.2: safer settings, a better wheel, a smarter Uninstaller

## ⚙️ Settings you change on purpose
- Changes show straight away, but are only kept when you press **Save**. **Discard** puts everything back
- Closing the window with unsaved changes asks first
- **Reset to defaults** on the General, Look and Formats pages
- Scrolling down a page never changes a setting by accident

## 🎡 A better wheel
- Every style redesigned: clearer text at every size, depth, a soft glow on the option you point at, rounded petals
- Long names go onto two lines instead of being cut, and the file name in the middle fits
- The small wheel is a little bigger, so its text is easy to read

## 🧹 Corefold Uninstaller
- New **Last used** column: when you last opened each app
- **Show:** apps not used for 3 months, big apps, recently installed, or the ones that start with Windows
- Apps that only run in the background are never listed as unused

## 🔄 Corefold Converter
- Its own icon, so it's easy to tell apart from Corefold itself
- New: convert pictures to **AVIF** (about half the size of a JPG)

## ☁️ Coming soon
- **Corefold Cloud**: OneDrive, Google Drive, Dropbox and more in one window

Your settings, history and backups are kept.
