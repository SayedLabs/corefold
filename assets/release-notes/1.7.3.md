Corefold 1.7.3

New: Corefold Archive
- Its own page: drop an archive to open it, or files to pack them. Recent archives listed.
- Drag files out of an archive straight into any folder.
- Open a file inside a ZIP or 7z, change it, and save it back into the archive.
- Rescue damaged archives: every file that can still be read goes into a new ZIP. The original isn't touched.
- Unpack archives inside archives in one go.
- Double-click to open: Corefold shows up under "Open with", with a button to make it the default.

Lighter
- The background remover runs in its own helper and quits when done, so its memory goes back to Windows.
- Memory a job used is handed back a few seconds after it ends.
- Big photos need half the memory. Pages you rarely open are built only when you open them.

Coming soon
- Corefold Capture, Space and Clipboard. Upcoming tools now share one "Coming soon" row.
