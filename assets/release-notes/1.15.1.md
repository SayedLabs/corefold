Fixes
- With the keyboard, Tab now goes from the bar at the top to the Files heading (Settings and the use that's open) and then into the page, on every Files page. On Convert, the heading used to come last.

Smoother
- After a job (like drawing a PDF's small page pictures or opening a big Cloud folder), the tidy-up that frees memory stops the window for a much shorter moment.
- During long jobs with the window open (like extracting 200,000 files or drawing page pictures for 40 PDFs), Corefold looks for memory to free less often, so the window stops less.
- The first time the window opens after an update, it no longer stops for a moment while Corefold gets the search (Ctrl + K) ready for the Formats settings.
