## Corefold 1.5.2: bug fixes

- Resizing, rotating or watermarking an animated GIF or WebP keeps it animated
- Fit size explains that it can't shrink animated pictures yet, instead of quietly making a still one
- Damaged videos, songs and PDFs show a clear message instead of technical errors
- Windows opened from the right-click menu (like Resize…) now come to the front instead of hiding behind Explorer
- Corefold no longer holds up Windows when shutting down or signing out
- Cancel now stops conversions done with LibreOffice
- Jobs are no longer reported as failed when antivirus briefly locks a temporary file
- Leftover temporary files from interrupted jobs are cleaned up
- The history file stays small even after converting thousands of files
- Extracting archives no longer counts as "space saved"
- Folder names with a dot (like "v1.2 photos") keep their full name
- Long option names on the wheel end in "…" instead of being cut off
