date: 2026-10-26

Safer
- A file's name that looks like web code now always shows as plain text in questions and messages, so it can't make Windows connect to another computer.
- Signing in to Google Drive can't be cut short by another web page open in the browser.
- Archives that would unpack to more than the disk can hold (archive bombs) are refused before anything is written, and stopped part way if they hold more than they say; what was unpacked is cleaned up.
- A PDF page that claims to be enormous is turned into a picture of sensible size instead of using up the memory.

Smoother
- Switching light/dark, the language, or a tool on/off now fades smoothly instead of jumping.
- The PDF page opens instantly the first time.
- Icons are drawn once, so changing the look is faster and uses less memory.
