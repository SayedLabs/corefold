Corefold 1.7.4

Settings, ready for more tools
- One Settings page with a tab for the app and one for each tool: General, Appearance, Converter (Options, Wheel, Formats), Uninstaller, Archives.
- A Settings button at the top of every tool.
- New: when a program counts as unused, how long backups are kept, a restore point ticked by default; how "Extract here" works, unpacking archives inside by default, recent archives on or off.

Archives
- Huge archives open at once (60,000 files: 0.3 s instead of 7.7 s).
- Extract here and Extract to…, a More menu, a right-click menu, Enter / Delete / Ctrl+F.
- Asks before closing if a changed file wasn't saved back; sorts names like File Explorer.

Fixes
- Arabic: sizes and app, file and archive names read in the right order.
- Some buttons and options briefly opened as their own little windows.
- Rescuing damaged archives works in read-only places; dragged-out copies are cleaned up.
