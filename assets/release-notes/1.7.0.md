# Corefold 1.7.0: a new look, and safer than ever

## 🎨 A new, darker look
- A calm black design with fine lines, and the accent colour only where it matters
- A new sidebar with **Tools** and **Settings**, and a first look at what's coming: **Archive**, **Player** and **Viewer**
- A cleaner wheel: the option you point at gets a soft glow and a bright edge instead of a solid block, with bigger icons
- Rounded tray menu with icons, quieter buttons, tidier pages
- A refined logo and app icon, sharper at small sizes
- A softer, warmer "done" sound

## 🛡️ Safer
- **Files taken out of a downloaded archive keep Windows' "from the internet" mark**, so Windows still warns before running them and Office still opens them in Protected View
- **Office documents are turned into PDFs with macros switched off**
- A file that pretends to be a video can't make Corefold go online
- Opening a file from inside an archive can never reach a file outside it
- **Uninstall is even more careful:**
  - Windows, system settings and every account's personal folders (Documents, Desktop, Downloads, OneDrive…) can never be removed, whatever happens
  - Only things that are clearly the app's own are ticked; a folder shared with other programs is never ticked
  - Links and junctions are never followed
  - If the app still looks installed, "Remove leftovers only" warns you and ticks nothing
  - The backup is saved as it goes, so everything can be put back even if the PC switches off half-way
  - Backups of removed apps are kept when you remove Corefold itself
- Updates are checked and size-limited; the app and its tools are built from verified downloads, with an up-to-date 7-Zip

## 🐛 Fixes
- Making ZIP and 7z files, extracting only some files, adding or removing files in an archive and opening a file from an archive work again on Windows
- A locked Word or Excel file no longer keeps the PDF export waiting for minutes
- Very large pictures can no longer use up all the memory
- Long videos no longer make Corefold hold on to lots of memory while converting
- Clipped button text, the volume row and the History page spacing are fixed

Your settings, history and backups are kept.
