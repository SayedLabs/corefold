PDF
- Make searchable: a scanned PDF gets its words read (Arabic too, once Arabic is added in Windows' languages), so you can search it, select and copy its text. The pages look exactly as they did.
- Pages that already have text are left as they are, and a locked PDF keeps its password.

Archive
- Arabic names in old ZIP files (made on older Windows or by other apps) come out right, by themselves.
- If the names still look wrong, pick how to read them from More > File names.
- New ZIPs keep Arabic and other names right on every PC.

Converter
- Video quality: High, Balanced, Smaller file or Smallest file, for MP4, MOV, WebM and MKV.
- Video size: the same as the video, or up to 4K, Full HD, HD or 480p. A video is only ever made smaller, and keeps its shape.
- Both are on the Converter's Options page.

Unlock
- Close and…: one click closes the programs holding a file, then deletes, moves or renames it.
- Copy to…: copy a file a program has open, without closing anything (most programs allow it).
- When the PC restarts…: move or rename a file that won't let go, as the PC next starts.

Cloud
- Move to: move files and folders to another account. Each item is deleted from where it was only once all of it got across, and goes to that account's deleted files, so it can be put back.
- Copying between accounts goes one file at a time, so a big folder never needs its whole size free on this PC.
- Select all in a folder of thousands of files is instant.
