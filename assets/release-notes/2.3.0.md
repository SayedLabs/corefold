New
- Startup is back in Computer, switched on: every program that starts with Windows in one list (apps, Store apps and scheduled tasks), each with a switch that works the same way as Task Manager, so nothing is deleted. You can also put a program off until a minute after you sign in, spot what added itself since you last looked, and tidy away lines left behind by programs you removed.

Changed
- Settings are easier to read: the option you picked stands out in dark mode too, each page is grouped under clear headings, and a short "Saved" shows beside the page's name when a change is kept. Reset to defaults now asks first.
