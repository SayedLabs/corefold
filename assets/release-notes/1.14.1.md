date: 2026-10-26

Fixes
- Converting, packing or unpacking into a folder Windows won't let you save in (like one in Program Files) no longer runs for ever: what's made goes to Downloads › Corefold, and Corefold says so.
- Packing a file another program is holding no longer leaves it out of the archive without a word: Corefold says the file is open in another app, and no partial archive is left.
- An archive that another program is holding is no longer called damaged.
- Converting a folder where no picture could be saved is now an error that says why, instead of an empty folder.
- Packing or adding files deep inside many folders (past Windows' old 260-letter limit) now works, and a path that's too long is said plainly.

Smoother
- The Startup page reads Store apps' logos in the background, so it can't hold up the window.
