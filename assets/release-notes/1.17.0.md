date: 2026-11-01

New
- PDF: Page size makes every page A4, Letter, A3, A5 or Legal, with what's on it fitted inside (links and notes move along).
- PDF: Trim edges cuts away the empty white edges around every page (they are hidden, not taken out of the file).
- PDF: Flatten makes filled-in forms, notes and stamps part of the page, so they can't be changed any more. A locked PDF keeps its password.
- PDF: Repair rebuilds a damaged PDF into a new copy with every page that can be saved.
- PDF: Reverse the order and Mix on the board of pages: mix two PDFs a page from each in turn, or put a two-sided scan back in order (the fronts in one file, the backs in another, in reverse).

Safer
- The Uninstaller no longer mistakes another program that's open for part of an app's uninstaller. Before, it could wait for it, bring its window up, or stop it. When it closes the programs still running from an app's folder, it checks each one is still that program first.
- The administrator helper also checks the backup's registry and scheduled task files before putting them back, and uses its own copies of them, so a file changed after the permission prompt is refused.

Fixes
- When Windows doesn't allow something (a folder Cloud saves into, a list saved from Space or the Uninstaller, a job that stops), Corefold says what went wrong in plain words instead of Windows' own error text.
