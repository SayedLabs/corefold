date: 2026-11-06

New
- Rakiza Core 2.0: Corefold is now Rakiza Core, by Rakiza Labs, with a new look. Your settings, history, pins and shortcuts come along by themselves.
- A clearer sidebar: each section shows its tools under it, Updates is now inside About, and the tray menu is grouped.
- Rename: rename hundreds of files at once with numbers, dates, find and replace, a photo's date or a song's title. Every new name is shown before anything changes, and History can undo it.
- Check: make sure a download is the real file. Compare its SHA-256, SHA-1 or MD5 with the code on the website, compare two files, or check a whole list of codes.
- Backup: copy your important folders to another drive and keep them up to date by themselves. Older versions of changed or deleted files are kept for 90 days, in plain folders you can open in File Explorer.
- Network: see which programs are using the internet and where they connect, a live speed graph, the data used, and the ports other devices can reach. The speed test runs only when you ask. No administrator needed.
- Space: the map now goes down to the files, the list beside it has columns, a look shows how far along it is, and "See what fills this" is in File Explorer's right-click menu. It can also find similar photos.
- Converter: change a song's details and album cover (MP3, M4A, FLAC, OGG, Opus) without touching the sound, take a part out of a video or song, and trim fast with no quality lost.
- PDF: every piece on a page can be picked and deleted, bookmarks can be added and arranged, and page numbers can be in Arabic digits.
- The new tools (Rename, Check, Backup and Network) wait switched off in their section: turn on the ones you want.

Changed
- Updates no longer bring up Windows' permission question every time, and a standard account no longer needs an administrator's password to update. This one update to 2.0 still asks once.
- The Player has moved to Rakiza Play. Videos and music now open in the program Windows plays them with.

Smoother
- Space draws its map much faster (25 s down to 3.5 s on a test drive), with or without administrator rights.
- Making a very big PDF smaller no longer holds the window up.
- The Apps page no longer pauses the first time it opens.

Safer
- Cloud: deleting a folder on an FTP server never follows a link to a folder somewhere else on the server, and WebDAV refuses a download sent on from a secure address to an unsecured one.
- Saving or copying a folder stops with a plain message when a link leads round in a circle.
- Song details: if the new copy of a song comes out shorter, the song is left exactly as it was.
