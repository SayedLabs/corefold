How it works

Hold Shift and drag

Start dragging any file in File Explorer or on your desktop, or right-click it and pick what you want from the Corefold menu.

Pick from the wheel

A wheel of options appears. Options that don't fit your file are greyed out and tell you why.

Done

The new file appears next to the original. The original is never changed.

Is it safe?

  • Your files stay on your PC. Corefold doesn't upload anything. It only goes online to check for its own updates. Read the privacy policy.
  • The code is public. Anyone can read every line on GitHub, and every download is built there automatically from that code.
  • Originals are never changed. Corefold always makes a new file.
  • Easy to remove. Uninstall it like any app, from Windows Settings or from inside Corefold.

"Windows protected your PC"?

Windows shows this for new apps from small makers that haven't bought a code-signing certificate yet. It isn't a virus warning. Click More info, then Run anyway.

Questions

Is it really free?

Yes. No ads, no account, no trial.

Does it work without internet?

Yes, everything happens on your PC, even removing backgrounds.

How do I update it?

You don't have to. Corefold checks for new versions and updates itself in one click, keeping your settings.

Can it make RAR files?

It opens and extracts RAR files. Making new RAR files isn't possible for free apps (the format belongs to WinRAR), so Corefold makes ZIP and 7z files, which open everywhere.

How do I uninstall it?

Windows Settings → Apps → Installed apps → Corefold → Uninstall. Or in Corefold: About → Uninstall.
